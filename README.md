# 18650-Battery-Data
Under laboratory-simulated BESS operating conditions at 25°C, an equivalent 14-day dataset was collected using 18650 lithium iron phosphate cells, covering both frequency regulation and peak shaving scenarios.
The experiments utilized GZNF 18650 LiFePO₄ batteries and were conducted using the NEWARE-8008 battery testing system to simulate BESS operating profiles. Two charge-discharge cycles were used to emulate one day of BESS operation, with frequency regulation applied throughout the entire period.
To accelerate the testing process, the time scale was compressed by a factor of four compared to real BESS operation. All tests were carried out in a DHS-50 temperature chamber, maintaining a constant ambient temperature of 25°C.
